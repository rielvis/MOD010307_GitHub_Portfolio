# Microgame: Rubitals

## Concept
There is a spaceship and it needs use gravity fields to reach the planet destination.

## Player Action
Using drag input, the player must arrange gravitational bodies to line up the launch trajectory of the ship so it can reach the planet destination.

## Success / Failure
**Success condition:**  The ship reaches the planet destination set as a trigger collider.

**Failure condition:**  The ship misses the planet destination and leaves the play area.

## Programming Focuses
This microgame primarily demonstrates:
- Physics gameplay
- Velocity
- Gravity
- Triggers

This microgame specifically and additionally demonstrates:
- Vector calculation
- Quaternion rotation setting
- Boolean logic for game control

## How the Programming Works
[MG2GameManager.cs](MobileGameProject\Assets\Scripts\Microgames\MG2_Rubitals\MG2GameManager.cs) inherits [MicrogameBehaviour.cs](MobileGameProject\Assets\Scripts\Framework\MicrogameBehaviour.cs). It is attached to the GameManager object in [MG2_Rubitals.unity](MobileGameProject\Assets\Scenes\MG2_Rubitals.unity) to handle game management per the [framework](Documentation\Framework.md).

[MG2Session.cs](MobileGameProject\Assets\Scripts\Microgames\MG2_Rubitals\MG2Session.cs) inherits [MicrogameSession.cs](MobileGameProject\Assets\Scripts\Framework\MicrogameSession.cs). It is attached to the MicrogameSession object in [MG2_Rubitals.unity](MobileGameProject\Assets\Scenes\MG2_Rubitals.unity) to handle microgame session management per the [framework](Documentation\Framework.md).

[GravityController.cs](MobileGameProject\Assets\Scripts\Microgames\MG2_Rubitals\GravityController.cs) inherits MonoBehaviour and does the following:
- Variables are held for the vector between the centre of the gravity-field object this script is attached to the anything that enters the trigger area of the same object, and a `float gravityStrength` for how strongly the gravity-field object should pull.
- At `Start()`, `gravityStrength` is set to `1f`.
- Declares an `OnTriggerStay2D()` function to calculate and apply the effect of gravity on anything that enters the gravitational field this script is attached to, via `collider.attachedRigidbody.AddForce()`.

[PlanetController.cs](MobileGameProject\Assets\Scripts\Microgames\MG2_Rubitals\PlanetController.cs) inherits MonoBehaviour and does the following:
- Uses `UnityEngine.EventSystem` to also inherit IPointerDownHandler and IPointerUpHandler and declare `OnPointerDown()` and `OnPointerUp()` to program drag functionality.
- Holds a variable reference for `ShipController ship` to check if it has been launched, as well as variables for `Camera cam`, `Vector3 touchedScreenPosition`, and `bool isDragging` to program drag functionality.
- Declares a `GetTouchedPosition()` function to assign the `Pointer.current.position` to `touchedScreenPosition`, so wherever you touch is recorded.
- Declares a `ChangePosition()` function to update the planet object's position using `cam.ScreenToWorldPoint()` and then an additional setting of the position to keep `position.z` at 0, so it stays in 2D view.
- On `Start()`, `cam` and `ship` are assigned via `GameObject.Find().GetComponent<>()`.
- With `OnPointerDown()` and `OnPointerUp()`, if the ship has not been launched, `isDragging` is set to true/false so that update can run accordingly. 
- In `Update()`, `isDragging` is checked to be true before running functions `GetTouchedPosition()` and `ChangePosition()`.

[ShipController.cs](MobileGameProject\Assets\Scripts\Microgames\MG2_Rubitals\ShipController.cs) inherits MonoBehaviour and does the following:
- Holds variables for the ship object's `Rigidbody2D rb`.
- Holds variables `Transform nose` and `Transform back` in order to calculate`Vector2 launchVector` which holds the direction the ship should launch towards.
- Holds variables for `float launchSpeed` to set how fast the ship launches and `bool hasLaunched` to check whether the ship has been launched, as referred to by [PlanetController.cs](MobileGameProject\Assets\Scripts\Microgames\MG2_Rubitals\PlanetController.cs) to control when the player can drag the planets.
-  Holds a variable to [MG2Session.cs](MobileGameProject\Assets\Scripts\Microgames\MG2_Rubitals\MG2Session.cs) in order to call `MicrogameSession.Finish()` depending on where the ship ends up during the game.
- On `Awake()`, `rb` is assigned via `GetComponent<>()`.
- Declares a `SetRandomRotation()` function to randomise which direction the ship is pointing in.
- Declares a `GetLaunchVector()` function to calculate the direction the ship needs to travel in using GameObjects assigned to `Transform nose` and `Transform back`.
- Declares a `public void LaunchShip()` to set the ship's velocity to the `launchVector` multiplied by the `launchSpeed` and set `hadLaunched` to true. It is public so it can be assigned to a UI button.
- Declares a `FaceVelocity()` function to make the ship point in the direction that it is moving.
- On `Start()`, `hasLaunched` is set to false, `launchSpeed` is assigned a value, and calls `SetRandomRotation()` and `GetLaunchVector()`.
- With `OnTriggerEnter2D`, the ship detects if they have reached the destination planet and triggers `MicrogameSession.Finish(true)` to indicate a win. It also uses `OnTriggerExit2D`, detecting if it leaves the play area and triggering `MicrogameSession.Finish(false)`.
