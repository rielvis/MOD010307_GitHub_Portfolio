# Microgame: DuckDuck

## Concept
The player is a duck in a field, and there are hunters trying to shoot them down.

## Player Action
Using swipe gestures, the player must direct the bird away from where the hunters are aiming until they run out of ammunition.

## Success / Failure
**Success condition:**  The player stays alive until the "Hunters Remaining" reaches 0.

**Failure condition:**  The player gets caught and shot in a hunter target zone.

## Programming Focuses
This microgame **primarily** demonstrates:

This microgame specifically and additionally demonstrates:
